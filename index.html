Roadmap

学习路线

01

Python 简介及安装环境

理解 Python 的应用场景，完成解释器、编辑器和常用包管理工具安装。

02

Python 基本数据类型、变量和运算符

掌握数字、字符串、列表、元组、字典、集合、变量命名和常用运算。

03

Python 分支、循环与条件

使用 if、for、while 和条件表达式描述程序流程。

04

函数及其变量作用域、模块和包

把重复逻辑封装成函数，理解局部变量、全局变量、模块导入和包组织。

05

Python 面向对象、函数式编程及高级语法

学习类、对象、继承、迭代器、生成器、装饰器和常用函数式工具。

06

数据分析一 NumPy

掌握数组、广播、索引、统计计算和向量化运算。

07

数据分析二 Pandas

处理表格数据、时间序列、缺测值、分组统计和文件读写。

08

数据分析三 Xarray

面向多维标注数组，处理 NetCDF、气象格点数据和维度选择。

09

数据绘图一 Matplotlib

绘制折线图、散点图、直方图、子图、色标并导出高质量图片。

10

数据绘图二 Cartopy

绘制地图、投影、海岸线、经纬度网格和空间数据可视化。

Examples

示例代码

读取 CSV 并绘制折线图
import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_csv("temperature.csv")

plt.plot(data["date"], data["temp"])
plt.xlabel("Date")
plt.ylabel("Temperature")
plt.title("Daily Temperature")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

FAQ

常见问题

为什么我的 Python 找不到安装的库？

通常是解释器环境不一致。请确认终端、编辑器和安装命令使用的是同一个 Python 环境。

提交问题时应该提供什么？

请提供课程背景、最小可复现代码、完整报错截图或文本、输入数据格式，以及你已经尝试过的方法。

版主不能解决的问题怎么办？

版主会整理问题背景和已有尝试，再对接相关教师。共性问题可发展为专题讲座或答疑工作坊。
