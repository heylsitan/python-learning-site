Examples

示例代码

读取 CSV 并绘制折线图
import pandas as pd
import matplotlib.pyplot as plt

data = pd.read_csv("temperature.csv")

plt.plot(data["date"], data["temp"])
plt.xlabel("Date")
plt.ylabel("Temperature")
plt.title("Daily Temperature")
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

FAQ

常见问题

为什么我的 Python 找不到安装的库？

通常是解释器环境不一致。请确认终端、编辑器和安装命令使用的是同一个 Python 环境。

提交问题时应该提供什么？

请提供课程背景、最小可复现代码、完整报错截图或文本、输入数据格式，以及你已经尝试过的方法。

版主不能解决的问题怎么办？

版主会整理问题背景和已有尝试，再对接相关教师。共性问题可发展为专题讲座或答疑工作坊。
