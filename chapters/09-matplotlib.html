01

绘图思想与对象模型

为什么气象绘图要学 Matplotlib？

  • 它是 NumPy、Pandas、Xarray、Cartopy 等科学绘图库最常用的底层绘图接口。
  • 它既能画普通统计图，也能画二维空间场、剖面图、风矢量、多面板综合图。
  • 它的优势不只是“画图”，而是能够精确控制坐标轴、刻度、色标、图例、层级和输出格式。

官方网站：https://matplotlib.org/

推荐导入方式

课堂和科研脚本中建议以对象式 API 为主：先得到 fig 和 ax，再通过 ax.plot()、ax.contourf() 等方法控制具体子图。这样在多子图、双坐标轴、共享色标时更稳定。

课堂判断

如果图里只有一个坐标区，plt.plot() 可以快速演示；如果图里有多个坐标区、多个色标或地图投影，应切换到 fig, ax = plt.subplots() 的对象式写法。

安装与导入
conda install matplotlib

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.ticker as mticker

Matplotlib 的核心对象

Figure

整张画布，决定输出尺寸、分辨率和全局布局。

Axes

真正绘图的坐标区。一个 Figure 可以包含多个 Axes。

Axis

横轴或纵轴对象，负责刻度位置、刻度标签和格式化。

Artist

图中几乎所有元素都是 Artist，包括线、点、文字、图例和色标。

Line / Marker

折线与点标记，常用于时间序列或廓线。

Collection

散点、等值线填色、矢量场等批量图元常返回 Collection。

Legend

解释不同曲线、点组或类别。

Colorbar

解释颜色与数值之间的映射关系。

成图前先问三个问题

变量是什么？

时间序列、类别比较、二维空间场、风矢量还是概率分布？变量类型决定图形类型。

结论是什么？

突出趋势、极值、异常、空间中心、风向风速，还是变量之间的关系？结论决定标注和色标。

读者怎么读？

单位、坐标范围、刻度间隔、图例位置、色标范围和保存分辨率，都要服务于读图。

标准绘图流程

1整理数据维度、单位和缺测值
2创建 Figure 与 Axes
3绘制主体图层
4补充坐标轴、刻度、图例和色标
5检查并保存图片
最小但规范的对象式流程
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-np.pi, np.pi, 200)
y = np.sin(x)
z = np.cos(x)

fig, ax = plt.subplots(figsize=(6.4, 4.0), dpi=120)
ax.plot(x, y, color="tab:blue", lw=2, label="sin(x)")
ax.plot(x, z, color="tab:red", lw=2, ls="--", label="cos(x)")
ax.set_title("Trigonometric Functions")
ax.set_xlabel("x")
ax.set_ylabel("value")
ax.grid(ls="--", alpha=0.35)
ax.legend(frameon=False)
fig.tight_layout()
plt.show()

Figure 尺寸与分辨率

figsize 使用英寸，dpi 是每英寸像素数。画布像素尺寸为 figsize * dpi。课堂展示图可以较宽，论文图应先按最终版面宽度设计。

  • 单栏图：可从 figsize=(3.5, 2.6) 开始。
  • 课堂屏幕图：可用 figsize=(8, 4.5)。
  • 保存图：通常 dpi=300 起步。
Figure 尺寸
fig = plt.figure(figsize=(6.4, 4.8), dpi=100)

fig, ax = plt.subplots(figsize=(8, 4), dpi=150)

Axes 创建方式

plt.subplots() 适合绝大多数图；GridSpec 适合复杂排版；fig.add_axes() 适合手动放置色标或小图。

创建 Axes
fig, ax = plt.subplots()
ax.plot(x, y)

fig, axes = plt.subplots(2, 2, sharex=True)
axes[0, 0].plot(x, y)

fig = plt.figure()
ax = fig.add_axes([0.12, 0.12, 0.75, 0.75])

04

坐标轴、刻度和网格

坐标轴控制比样式更重要

气象图常见问题不是颜色不好看，而是坐标范围、刻度间隔或单位不清楚。应优先设置 xlim、ylim、主副刻度、刻度方向和网格线。

  • set_xlim() / set_ylim() 控制显示范围。
  • tick_params() 控制刻度方向、长度、字号和四边显示。
  • MultipleLocator、MaxNLocator、FixedLocator 控制刻度位置。
  • grid(which="both") 可同时显示主副刻度网格。
主副刻度与网格
fig, ax = plt.subplots()
ax.plot(x, y, lw=2)
ax.set_xlim(0, 20)
ax.set_ylim(0, 1.1)

ax.xaxis.set_major_locator(mticker.MultipleLocator(5))
ax.xaxis.set_minor_locator(mticker.MultipleLocator(1))
ax.yaxis.set_major_locator(mticker.MultipleLocator(0.2))
ax.yaxis.set_minor_locator(mticker.MultipleLocator(0.1))

ax.tick_params(which="major", direction="in", length=5, top=True, right=True)
ax.tick_params(which="minor", direction="in", length=3, top=True, right=True)
ax.grid(which="major", ls="--", lw=0.6, alpha=0.6)

标签、标题和时间坐标

坐标轴标签必须包含变量名和单位。时间序列不要把日期硬改成字符串编号，应优先保留 Pandas 时间类型，再使用日期格式化。

时间轴示例
import matplotlib.dates as mdates

fig, ax = plt.subplots(figsize=(9, 3))
ax.plot(df["date"], df["temp_max"], label="Tmax")
ax.set_ylabel("Temperature (deg C)")
ax.xaxis.set_major_locator(mdates.DayLocator(interval=5))
ax.xaxis.set_major_formatter(mdates.DateFormatter("%m-%d"))
ax.tick_params(axis="x", rotation=45)
ax.legend(frameon=False)
fig.tight_layout()

坐标轴检查清单

范围

是否突出关键区间，是否误导性截断？

单位

温度、降水、风速、位势高度等单位是否写在标签或色标上？

刻度

刻度是否太密、太少或不等距？主副刻度是否有必要？

网格

网格是否帮助读数，而不是压过主体图层？

05

样式与标注

颜色、线型和标记

折线图的样式参数不仅是美化工具，也用于区分变量、实验组和显著性。黑白打印或投影环境下，线型和标记比颜色更可靠。

参数作用例子
color / c线条或点颜色"tab:blue"、"#d94841"
linestyle / ls线型"-"、"--"、":"
linewidth / lw线宽0.8、2
marker点标记"o"、"s"、"^"
alpha透明度0.2、0.75
zorder图层顺序重要线条放在更高层
样式参数
ax.plot(x, y1, color="k", lw=1.8, marker="o",
        markerfacecolor="white", markeredgewidth=1.2,
        label="Observation")
ax.plot(x, y2, color="tab:red", ls="--", lw=1.5,
        label="Simulation")

# fmt 写法：[marker][line][color]
ax.plot(x, y3, "s:b", label="Experiment")

图例和注释

图例用于解释类别，注释用于突出结论。不要把图例放在遮挡峰值、中心或显著区域的位置。

  • legend(loc=...) 控制图例位置。
  • frameon=False 可减少视觉干扰。
  • annotate() 可以用箭头标出极值或事件。
Legend 与 Annotation
ax.legend(loc="upper left", ncol=2, frameon=False)

imax = np.argmax(temp)
ax.annotate("Heat peak",
            xy=(date[imax], temp[imax]),
            xytext=(date[imax], temp[imax] + 3),
            arrowprops={"arrowstyle": "->", "color": "0.2"})

中文和负号

如果图中必须出现中文，需确认运行环境有可用中文字体；同时设置 axes.unicode_minus=False，避免负号显示为方块。

中文字体设置
plt.rcParams["font.sans-serif"] = ["SimHei", "Microsoft YaHei"]
plt.rcParams["axes.unicode_minus"] = False
06

等值线、色标和风场

二维场绘图：从数据范围到色标范围

气象二维场图的关键是 X、Y 与 Z 的维度匹配，以及 levels、cmap、norm、extend 的一致性。多幅图比较时，不能让每幅图自动生成不同色标范围。

contour 与 contourf

  • contour 画等值线，适合高度场、气压场、温度线。
  • contourf 画填色，适合异常场、降水、湿度或背景变量。
  • 等值线参数常是复数形式：colors、linewidths、linestyles。
  • 线值标签由 ax.clabel() 添加，fmt 控制显示格式。
等值线与标签
x = np.linspace(70, 140, 141)
y = np.linspace(15, 55, 81)
X, Y = np.meshgrid(x, y)
Z = 5800 + 80 * np.sin(X / 10) * np.cos(Y / 8)

fig, ax = plt.subplots()
levels = np.arange(5520, 5921, 40)
cs = ax.contour(X, Y, Z, levels=levels,
                colors="k", linewidths=0.8)
ax.clabel(cs, inline=True, fmt="%.0f", fontsize=8)

色标的三种层次

色标不是装饰，而是数值解释系统。最基础是传入绘图返回对象；比较图时要统一 levels 或 norm；复杂版式可用 cax 或 axes_grid1 精确放置色标。

共享色标范围
from matplotlib.colors import TwoSlopeNorm

levels = np.arange(-6, 6.5, 0.5)
norm = TwoSlopeNorm(vmin=-6, vcenter=0, vmax=6)

fig, axes = plt.subplots(1, 2, figsize=(8, 3))
for ax, data, title in zip(axes, [anom1, anom2], ["A", "B"]):
    cf = ax.contourf(lon, lat, data, levels=levels,
                     cmap="RdBu_r", norm=norm, extend="both")
    ax.set_title(title)

fig.colorbar(cf, ax=axes, orientation="horizontal",
             pad=0.08, label="Temperature anomaly (deg C)")

离散色阶与边界

降水等级、风速等级、污染等级等变量更适合离散色阶。用 BoundaryNorm 可把数值边界和颜色边界绑定，避免颜色解释含糊。

BoundaryNorm
from matplotlib.colors import BoundaryNorm

bounds = [0, 0.1, 10, 25, 50, 100, 250]
cmap = plt.get_cmap("Blues", len(bounds) - 1)
norm = BoundaryNorm(bounds, cmap.N)

cf = ax.contourf(lon, lat, rain, levels=bounds,
                 cmap=cmap, norm=norm, extend="max")
fig.colorbar(cf, ax=ax, ticks=bounds, label="Rainfall (mm)")

风场可视化：风羽、箭头和流线

风场的基本输入都是位置 x, y 和分量 u, v。差别在于表达重点：barbs 更接近天气图符号，quiver 适合方向和大小对比，streamplot 更容易显示辐合、辐散和旋转结构。

风场绘图模板

  • 使用 [::step, ::step] 对网格抽稀。
  • quiverkey 相当于箭头图的图例。
  • 国内常用风羽单位规则可通过 barb_increments 调整。
Quiver / Barbs / Streamplot
step = 4
Q = ax.quiver(lon[::step], lat[::step],
              u[::step, ::step], v[::step, ::step],
              width=0.003, color="0.15")
ax.quiverkey(Q, 0.86, 1.04, 10, "10 m/s",
             labelpos="E", coordinates="axes")

ax.barbs(lon[::step], lat[::step],
         u[::step, ::step], v[::step, ::step],
         length=5, linewidth=0.5,
         barb_increments={"half": 2, "full": 4, "flag": 20})

ax.streamplot(lon, lat, u, v, density=1.4,
              color=np.hypot(u, v), cmap="viridis")

二维场检查清单

维度

X、Y、Z 是否能一一对应？经纬度是否需要 meshgrid？

色阶

是否显式设置 levels，多图比较是否共享范围？

零值

异常场是否以 0 为中心？是否需要 TwoSlopeNorm？

标签

等值线标签、色标单位、图题是否能说明变量和层次？

抽稀

风矢量是否过密？箭头图例是否说明参考风速？

遮挡

填色、等值线、风场、散点、文字的 zorder 是否合理？

多子图与版式

多子图不只是“摆在一起”

多子图的目的通常是比较：不同变量、不同时间、不同区域、不同实验。比较图应尽量共享坐标范围、色标范围和版式尺度。

多子图方法对比

方法适合场景示例
plt.subplot快速演示，不推荐复杂科研图长期使用。plt.subplot(2, 2, 2)
plt.subplots规则网格，多数课程图和练习图。fig, axes = plt.subplots(2, 2)
GridSpec子图宽高不等、需要独立色标轴。gs = fig.add_gridspec(2, 3)
subplot_mosaic用文字布局描述复杂面板。subplot_mosaic([["A", "B"], ["C", "C"]])
axes_grid1给现有 Axes 添加等高、等宽色标或附加轴。make_axes_locatable(ax)

共享色标和手动色标轴

当多幅图共享一个色标时，可把 ax=axes 传给 fig.colorbar()。如果要精确控制位置，则新建 cax。

GridSpec + cax
fig = plt.figure(figsize=(8, 4), constrained_layout=True)
gs = fig.add_gridspec(2, 3, width_ratios=[1, 1, 0.05])

ax1 = fig.add_subplot(gs[0, 0])
ax2 = fig.add_subplot(gs[0, 1])
ax3 = fig.add_subplot(gs[1, 0])
ax4 = fig.add_subplot(gs[1, 1])
cax = fig.add_subplot(gs[:, 2])

cf = ax4.contourf(X, Y, data4, levels=levels, cmap="RdBu_r")
fig.colorbar(cf, cax=cax, label="Anomaly")

双坐标轴要克制

twinx() 适合把单位不同但时间一致的两个变量放在一张图里，例如温度折线和降水柱状图。若两个变量没有共同解释目的，拆成上下两图通常更清楚。

双 y 轴
fig, ax1 = plt.subplots(figsize=(9, 3.5))
ax1.plot(date, temp, color="tab:red", label="Temperature")
ax1.set_ylabel("Temperature (deg C)", color="tab:red")

ax2 = ax1.twinx()
ax2.bar(date, rain, color="tab:blue", alpha=0.25, label="Rainfall")
ax2.set_ylabel("Rainfall (mm)", color="tab:blue")

fig.tight_layout()

综合练习

练习 A：Weather.csv 时间序列综合图

使用 Weather.csv 数据，绘制 New York 2015 年 7 月逐日最高温、最低温和降水量图。

  1. 用 Pandas 读取数据，筛选城市和日期。
  2. 用折线图绘制最高温和最低温，用半透明填充表示日较差。
  3. 用柱状图或双坐标轴绘制降水量。
  4. 设置日期刻度、标题、坐标轴标签、图例和网格线。
  5. 保存为 newyork_201507_weather.png，分辨率不低于 300 dpi。
练习骨架
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.dates as mdates

weather = pd.read_csv("Weather.csv", parse_dates=["date"])
ny = weather[(weather["city"] == "New York") &
             (weather["date"].dt.strftime("%Y-%m") == "2015-07")]

fig, ax1 = plt.subplots(figsize=(10, 4), dpi=150)
ax1.plot(ny["date"], ny["temp_max"], color="tab:red", label="temp_max")
ax1.plot(ny["date"], ny["temp_min"], color="tab:blue", label="temp_min")
ax1.fill_between(ny["date"], ny["temp_min"], ny["temp_max"],
                 color="tab:orange", alpha=0.18, label="daily range")
ax1.set_ylabel("Temperature")
ax1.grid(ls="--", alpha=0.35)
ax1.legend(loc="upper left", frameon=False)

ax2 = ax1.twinx()
ax2.bar(ny["date"], ny["precipitation"], alpha=0.25,
        color="tab:blue", label="precipitation")
ax2.set_ylabel("Precipitation")

ax1.xaxis.set_major_locator(mdates.DayLocator(interval=5))
ax1.xaxis.set_major_formatter(mdates.DateFormatter("%m-%d"))
fig.autofmt_xdate()
fig.suptitle("New York Weather, July 2015")
fig.tight_layout()
fig.savefig("newyork_201507_weather.png", dpi=300, bbox_inches="tight")

练习 C：风场抽稀与箭头图例

读取或构造 u、v 风分量，分别用 quiver 和 streamplot 表达风场结构。
