01

Matplotlib 简介

为什么使用 Matplotlib？

  • 是目前使用最广泛的 Python 绘图库之一。
  • 可以绘制二维和三维的多种图像。
  • 是许多高级绘图库和科学绘图工具的基础。

官方网站：https://matplotlib.org/

安装与引入

建议在 Conda 环境中安装，方便和 NumPy、Pandas、Xarray 等科学计算库配合使用。

安装与导入
conda install matplotlib

from matplotlib import pyplot as plt

Matplotlib 绘图对象

Figure

整个图形，也就是画布。

Axes

真正绘图的坐标区域，一个 Figure 可包含多个 Axes。

Title

图题，用于说明图形主题。

Legend

图例，用于区分多条曲线或多组数据。

Tick

坐标刻度。

Spines

连接刻度的坐标轴边框线。

Label

坐标轴标签。

Line / Marker

线条和点标记。

02

绘图流程

1准备绘图所需数据
2创建 Figure 对象
3为 Figure 添加 Axes 对象
4在 Axes 对象中绘图
5显示或保存图像
最小绘图流程
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-np.pi, np.pi, 100)
y = np.cos(x)
z = np.sin(x)

fig, ax = plt.subplots(figsize=(6.4, 4.8), dpi=100)
ax.plot(x, y, label="cos(x)")
ax.plot(x, z, label="sin(x)")
ax.legend()
plt.show()

Figure

Figure 是 Matplotlib 的最高一级对象，用来创建画布。常用参数包括：

  • figsize=(a, b)：画布长宽，单位为英寸。
  • dpi：每英寸像素点数，决定清晰度。

画布像素尺寸为 (a * dpi, b * dpi)。

Figure 尺寸
fig = plt.figure()

fig = plt.figure(figsize=(6.4, 4.8), dpi=100)

Axes

Axes 是矩形绘图容器。推荐使用 plt.subplots() 同时创建 Figure 和 Axes。

创建 Axes
fig, ax = plt.subplots()
ax.plot(x, y)

fig, axes = plt.subplots(nrows=1, ncols=2)
axes[0].plot(x, y)
axes[1].plot(x, z)
Style

绘图样式

颜色与线型

颜色可使用单字母或 CSS 十六进制颜色；线型用 linestyle 控制。

颜色含义线型含义
b蓝色-实线
g绿色--虚线
r红色-.点划线
k黑色:点线
颜色与线型
ax.plot(x, y, color="b", linestyle="-")
ax.plot(x, z, color="#d94841", linestyle="--")

# fmt 写法：[marker][line][color]
ax.plot(x, y, "o:r")

标记 Marker

参考菜鸟教程的 marker 说明，plot() 的 marker 参数控制每个点的形状，markersize 或 ms 控制大小，markeredgecolor / mec 控制边框色，markerfacecolor / mfc 控制填充色。

. 点, 像素点o 圆圈v 下三角 ^ 上三角< 左三角> 右三角s 方形 p 五边形* 星型+ 加号x 乘号 D 菱形d 瘦菱形| 竖线_ 横线
Marker 示例
ypoints = np.array([1, 3, 4, 5, 8, 9, 6])

plt.plot(ypoints, marker="o", ms=10)
plt.plot(ypoints, marker="*", ms=14, mec="r", mfc="#4CAF50")

标题、标签、刻度和网格线

常用接口包括 set_title()、set_xlabel()、set_ylabel()、set_xticks()、set_xticklabels() 和 grid()。

Ticks 与 Gridlines
fig, ax = plt.subplots()
ax.plot(x, y)
ax.set_title("Plot Sin(x)")
ax.set_xlabel("x")
ax.set_ylabel("sin(x)")
ax.set_xticks(np.pi * np.array([-1, -0.5, 0, 0.5, 1]))
ax.set_xticklabels([r"$-\pi$", r"$-\frac{\pi}{2}$", "0", r"$\frac{\pi}{2}$", r"$\pi$"])
ax.set_yticks([-1, 0, 1])
ax.grid(which="major", lw=1)

Spines 与图例

Axes 的 spines 字典包含 left、right、bottom、top。图例位置用 loc 控制。

Spines 与 Legend
ax.spines["right"].set_visible(False)
ax.spines["top"].set_visible(False)
ax.spines["bottom"].set_position(("data", 0))
ax.spines["left"].set_position(("data", 0))

ax.plot(x, y, label="sin(x)")
ax.plot(x, z, label="cos(x)")
ax.legend(loc="upper right")
03

绘图示例

柱状图 Bar Chart

用于比较多个项目的数据大小，例如纽约 2015 年 6-8 月晴天数。

months = ["JUN", "JUL", "AUG"]
sunny_times = [16, 19, 27]
fig, ax = plt.subplots()
ax.bar(months, sunny_times)

饼状图 Pie Chart

用于显示一系列数据占总量的比例。

weather = ["drizzle", "fog", "rain", "sun"]
counts = [3, 2, 6, 20]
fig, ax = plt.subplots()
ax.pie(counts, labels=weather)

散点图 Scatter Chart

用于显示两个变量的相关性，例如最高温和最低温。

fig, ax = plt.subplots()
ax.scatter(temp_max, temp_min)
ax.set_xlabel("temp_max")
ax.set_ylabel("temp_min")

等值线图 Contour Chart

用于表示二维场或三维结构的表面。

x = np.linspace(-2, 2, 100)
y = np.linspace(-2, 2, 100)
X, Y = np.meshgrid(x, y)
Z = np.sqrt(X**2 + Y**2)
fig, ax = plt.subplots()
cs = ax.contourf(X, Y, Z)
fig.colorbar(cs)

箱型图 Box Chart

用于显示数据离散情况，包括四分位数、中位数和异常值。

data = np.random.normal(1, 10, 50)
fig, ax = plt.subplots()
ax.boxplot(data)

直方图 Histogram Chart

用于描述连续变量的分布。

x = np.random.normal(20, 100, 100)
fig, ax = plt.subplots()
ax.hist(x, bins=[0, 20, 40, 60, 80])
ax.set_ylabel("counts")

三维绘图 3D Chart

导入 mpl_toolkits.mplot3d 后可以进行三维绘图。

from mpl_toolkits import mplot3d

fig = plt.figure()
ax = plt.axes(projection="3d")
ax.scatter(x, y, z)

填充图

使用 fill_between() 填充两条曲线之间的区域。

x = np.linspace(0, 10, 100)
y1 = x**2
y2 = 8 * x
fig, ax = plt.subplots()
ax.plot(x, y1, x, y2)
ax.fill_between(x, y1, y2, where=y2 > y1, facecolor="red", alpha=.2)

双坐标轴图

当两个变量在 y 轴上有不同意义或单位时，可使用双坐标轴。

x = np.linspace(0.1, 11, 20)
fig, ax1 = plt.subplots()
ax1.plot(x, np.exp(x))
ax1.set_ylabel("exp(x)")
ax2 = ax1.twinx()
ax2.plot(x, np.log(x), "r")
ax2.set_ylabel("log(x)")

文字及注释

使用 text() 和 annotate() 创建文字和注释。中文可通过字体文件设置。

fig, ax = plt.subplots()
ax.plot([1, 2, 3])
ax.text(1.1, 1.9, "y=x")
ax.annotate("x=1", xy=(1, 2), xytext=(1, 2.5),
            arrowprops=dict(facecolor="k"))
Subplot

多子图与色标

多子图方法对比

方法参数意义示例
subplot按 nrows * ncols 切分 Figure，索引从 1 开始。plt.subplot(2, 2, 2)
subplots同时创建 Figure 和 Axes 数组。fig, axes = plt.subplots(2, 2)
subplot2grid用网格位置控制子图跨行跨列。plt.subplot2grid((3, 3), (1, 0), rowspan=2, colspan=3)

多子图色标

多个子图的数据范围不同时，即使用相同色表，也可能产生色标不一致。可用 Normalize 或 levels 固定色标范围。

固定 levels
fig, axes = plt.subplots(1, 2)
levels = np.arange(0, 18, 2)
contourf1 = axes[0].contourf(x, y, data1, cmap="RdBu_r", levels=levels)
contourf2 = axes[1].contourf(x, y, data2, cmap="RdBu_r", levels=levels)
plt.colorbar(contourf1, ax=axes[0])
plt.colorbar(contourf2, ax=axes[1])
plt.tight_layout()
Save

图片保存

保存参数

  • 文件名后缀决定格式，例如 png、jpg、pdf。
  • 出版或报告图片通常建议 dpi > 300。
  • bbox_inches="tight" 可去掉图片周边空白。
保存图片
plt.savefig("figure.png", dpi=300, bbox_inches="tight")

fig.savefig("figure.pdf", dpi=300, bbox_inches="tight")

综合练习

Weather.csv 气象绘图练习

使用 Weather.csv 数据，绘制 New York 2015 年 7 月逐日最高温、最低温和降水量图。

  1. 用 Pandas 读取数据并筛选城市和日期。
  2. 使用折线图绘制最高温和最低温。
  3. 使用柱状图或双坐标轴绘制降水量。
  4. 添加标题、坐标轴标签、图例、网格线。
  5. 保存为 newyork_201507_weather.png，分辨率不低于 300 dpi。
练习骨架
import pandas as pd
import matplotlib.pyplot as plt

weather = pd.read_csv("Weather.csv")
ny = weather[(weather["city"] == "New York") & (weather["date"].str.startswith("2015-07"))]

fig, ax1 = plt.subplots(figsize=(10, 4), dpi=120)
ax1.plot(ny["date"], ny["temp_max"], label="temp_max")
ax1.plot(ny["date"], ny["temp_min"], label="temp_min")
ax1.set_ylabel("Temperature")
ax1.legend(loc="upper left")
ax1.grid(alpha=0.3)

ax2 = ax1.twinx()
ax2.bar(ny["date"], ny["precipitation"], alpha=0.25, color="tab:blue", label="precipitation")
ax2.set_ylabel("Precipitation")

plt.xticks(rotation=45)
plt.title("New York Weather, July 2015")
plt.tight_layout()
plt.savefig("newyork_201507_weather.png", dpi=300, bbox_inches="tight")
