Outcomes

  1. 说清本课程的定位：零基础入门，但以大学水平系统学习 Python 基础语法和科研应用。

Common Issues

本讲重点纠错

把 Python 和 conda 混为一谈

Python 是解释器，conda 是环境和包管理工具。排错时先确认当前激活的是哪个环境。

编辑器选错解释器

VS Code、终端和 JupyterLab 可能指向不同环境。课程练习要统一到课程环境。

只看 AI 是否生成代码

AI Agent 生成代码只是开始，还要检查地图边界、数据来源、颜色含义和结果是否合理。
