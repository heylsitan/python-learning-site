Matplotlib 04

样式、图例和标注

样式服务于区分变量和突出结论，不是单纯装饰。

基础必学建议 35 分钟

学习目标

  1. 能用颜色、线型、marker 区分多条曲线。
  2. 能放置不遮挡主体的图例。
  3. 能用注释突出极值或关键事件。

核心概念

本科生常把样式理解为“好看”。在科学图中，样式首先用于表达变量差异、实验组差异和显著事件。

color颜色
linestyle线型
marker点标记
zorder图层顺序
最小可运行代码
import numpy as np
import matplotlib.pyplot as plt

days = np.arange(1, 16)
obs = 20 + 0.7 * days + np.sin(days)
sim = 19 + 0.8 * days + 0.5 * np.cos(days)
imax = np.argmax(obs)

fig, ax = plt.subplots(figsize=(7, 3), dpi=120)
ax.plot(days, obs, color="k", lw=2, marker="o",
        markerfacecolor="white", label="Observation")
ax.plot(days, sim, color="tab:red", lw=1.8, ls="--", label="Simulation")
ax.annotate("peak", xy=(days[imax], obs[imax]),
            xytext=(days[imax] - 4, obs[imax] + 2),
            arrowprops={"arrowstyle": "->", "color": "0.2"})
ax.set_xlabel("Day")
ax.set_ylabel("Temperature (deg C)")
ax.legend(loc="upper left", frameon=False)
ax.grid(ls="--", alpha=0.3)
fig.tight_layout()
plt.show()

常见错误与修正

只靠颜色区分

投影或黑白打印时难以区分。修正：同时使用线型和 marker。

图例遮挡峰值

读者看不到关键区域。修正：调整 loc 或放到图外。

中文乱码或负号异常

系统缺字体或 Unicode 负号显示失败。修正：设置中文字体和 axes.unicode_minus。

课堂练习

把图例移动到图外上方，并为模拟曲线添加三角形 marker。

小结

样式的优先级是：区分变量、突出结论、减少遮挡，最后才是美观。
