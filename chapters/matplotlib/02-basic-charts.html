学习目标

  1. 能根据变量类型选择合适图形。
  2. 能画折线图、散点图、柱状图、直方图和箱线图。
  3. 能解释图形选择和科学问题之间的关系。

核心概念

问题图形函数气象例子
随时间变化折线图plot逐日温度
两个变量关系散点图scatter观测与模拟对比
类别比较柱状图bar各月暴雨日数
分布形态直方图/箱线图hist/boxplot误差分布

最小可运行代码

这段代码构造一组小型天气数据，同时展示基础图形。学生可以逐个注释/取消注释观察差异。

基础图形合集
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
days = np.arange(1, 11)
tmax = 26 + 4 * np.sin(days / 10 * np.pi) + rng.normal(0, 0.5, 10)
tmin = tmax - rng.uniform(6, 10, 10)
rain_days = [3, 5, 8]
months = ["Jun", "Jul", "Aug"]
errors = rng.normal(0, 1.5, 80)

fig, axes = plt.subplots(2, 2, figsize=(8, 5), dpi=120)
axes[0, 0].plot(days, tmax, marker="o", label="Tmax")
axes[0, 0].plot(days, tmin, marker="s", label="Tmin")
axes[0, 0].legend(frameon=False)
axes[0, 1].scatter(tmax, tmin, c=days, cmap="viridis")
axes[1, 0].bar(months, rain_days, color="tab:blue", alpha=0.75)
axes[1, 1].hist(errors, bins=np.arange(-5, 5.5, 0.5), edgecolor="white")
fig.tight_layout()
plt.show()

常见错误与修正

用柱状图画连续时间序列

数据点很多时读图困难。修正：连续变化优先折线图。

散点图没有第三变量说明

颜色映射后没有色标。修正：保存 sc 并调用 fig.colorbar(sc)。

直方图 bins 随意

分布形态会被误读。修正：根据变量单位设置等距边界。

课堂练习

把示例中的误差直方图改成箱线图，并说明箱线图比直方图更适合回答什么问题。

小结

基础图形选择的标准不是“哪个函数熟”，而是“这个图能不能回答当前问题”。
