风矢量场可视化

这里的“矢量”指风的方向和大小，不是图片文件格式。

气象核心建议 40 分钟

学习目标

  1. 能解释风矢量场的 u、v 分量。
  2. 能用 quiver、barbs、streamplot 表达风场。
  3. 能对风场抽稀并添加参考箭头。

核心概念

风矢量场的基本输入是位置 x, y 和风分量 u, v。网格风场通常必须抽稀，否则箭头或风羽会互相遮挡。

最小可运行代码

这段代码构造一个旋转风场，并用箭头图和流线图并排比较。

风矢量场
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-2, 2, 25)
y = np.linspace(-2, 2, 25)
X, Y = np.meshgrid(x, y)
U = -Y
V = X
speed = np.hypot(U, V)
step = 2

fig, axes = plt.subplots(1, 2, figsize=(8, 3.5), dpi=120)
Q = axes[0].quiver(X[::step, ::step], Y[::step, ::step],
                   U[::step, ::step], V[::step, ::step],
                   speed[::step, ::step], cmap="viridis")
axes[0].quiverkey(Q, 0.8, 1.05, 2, "2 units", coordinates="axes")
axes[0].set_title("quiver")
axes[1].streamplot(x, y, U, V, color=speed, cmap="viridis", density=1.2)
axes[1].set_title("streamplot")
for ax in axes:
    ax.set_aspect("equal")
fig.tight_layout()
plt.show()

常见错误与修正

风矢量过密

箭头互相覆盖。修正：用 [::step, ::step] 抽稀。

没有参考箭头

读者不知道箭头长度代表多大风速。修正：添加 quiverkey。

术语混淆

风矢量场不是 SVG/PDF 矢量图格式。修正：页面中统一称“风矢量场”。

课堂练习

把 step 改为 1、3、4，比较箭头密度对读图的影响。

小结

风矢量场图先处理抽稀，再添加参考箭头，最后再考虑颜色映射。
