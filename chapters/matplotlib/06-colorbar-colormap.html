色标与颜色映射

色标是数值解释系统，不是装饰条。

首页本章首页上一节下一节
气象核心建议 45 分钟

学习目标

  1. 能给可映射对象添加 colorbar。
  2. 能用统一 levels 比较两幅图。
  3. 能用 TwoSlopeNorm 和 BoundaryNorm 处理异常场和等级场。

核心概念

cmap 决定颜色，levels 决定分级，norm 决定数值如何映射到颜色。多图比较时必须共享范围。

异常场通常需要让 0 位于色标中心；降水等级更适合离散边界。

最小可运行代码
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import TwoSlopeNorm

x = np.linspace(-3, 3, 120)
y = np.linspace(-2, 2, 90)
X, Y = np.meshgrid(x, y)
data1 = X * np.exp(-X**2 - Y**2)
data2 = data1 + 0.25 * np.sin(2 * Y)
levels = np.arange(-0.6, 0.65, 0.1)
norm = TwoSlopeNorm(vmin=-0.6, vcenter=0, vmax=0.6)

fig, axes = plt.subplots(1, 2, figsize=(8, 3), dpi=120)
for ax, data, title in zip(axes, [data1, data2], ["A", "B"]):
    cf = ax.contourf(X, Y, data, levels=levels,
                     cmap="RdBu_r", norm=norm, extend="both")
    ax.set_title(title)
fig.colorbar(cf, ax=axes, orientation="horizontal",
             pad=0.12, label="Anomaly")
plt.show()

常见错误与修正

未传入 mappable

fig.colorbar() 不知道解释哪个图层。修正：保存 cf 或 sc 并传入。

两幅图色标范围不同

颜色相同但数值不同。修正：共享 levels 和 norm。

降水等级颜色不清晰

连续色标不表达等级边界。修正：使用 BoundaryNorm。

课堂练习

把色标改为竖向，并将 levels 间隔从 0.1 改为 0.2，比较信息损失。

小结

色标必须和数据范围绑定。比较图先统一范围，再谈配色。
