对象模型与绘图流程

基础必学建议 35 分钟

学习目标

  1. 能说清 Figure、Axes、Axis、Artist 的关系。
  2. 能用对象式 API 完成一张基础图。
  3. 能按“数据、画布、主体、修饰、保存”的顺序组织脚本。

核心概念

Figure 是整张画布，Axes 是具体绘图区，Axis 管理横轴或纵轴刻度，Artist 是线、点、文字、图例等所有可见元素。

本科课堂建议默认使用 fig, ax = plt.subplots()。它比 plt.plot() 更适合多子图、共享色标和后续 Cartopy 课程。

最小可运行代码
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
y = np.sin(x)

fig, ax = plt.subplots(figsize=(6, 3), dpi=120)
ax.plot(x, y, color="tab:blue", lw=2, label="sin(x)")
ax.set_title("A first object-oriented Matplotlib figure")
ax.set_xlabel("x")
ax.set_ylabel("sin(x)")
ax.grid(ls="--", alpha=0.35)
ax.legend(frameon=False)
fig.tight_layout()
plt.show()

常见错误与修正

混用太多 plt 状态接口

复杂图中容易修饰错子图。修正：对具体 ax 调用 ax.plot()、ax.set_xlabel()。

不知道图例来自哪里

没有设置 label 就调用 legend()。修正：绘制线条时同步写 label。

忘记布局调整

标题或标签被截断。修正：保存前使用 fig.tight_layout()。

课堂练习

把示例中的 sin(x) 改成 cos(x)，再同时画出两条曲线并添加图例。

小结

对象式 API 的核心是：先有 fig 和 ax，再把所有图层和修饰都明确加到这个 ax 上。
