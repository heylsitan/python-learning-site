Matplotlib 03

坐标轴、刻度和网格

让读者知道变量、单位、范围和关键刻度。

基础必学建议 40 分钟

学习目标

  1. 能设置坐标范围、标签和单位。
  2. 能使用主副刻度控制读数密度。
  3. 能让日期轴保持清晰。

核心概念

坐标轴是科学图最容易被忽略的部分。气象图至少要明确变量名、单位、显示范围、刻度间隔和网格是否有助于读数。

  • set_xlim / set_ylim 控制范围。
  • MultipleLocator 控制等距刻度。
  • DateFormatter 控制日期显示。
最小可运行代码
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.dates as mdates
import matplotlib.ticker as mticker

date = pd.date_range("2015-07-01", periods=31)
temp = 28 + 4 * np.sin(np.linspace(0, 2 * np.pi, 31))

fig, ax = plt.subplots(figsize=(8, 3), dpi=120)
ax.plot(date, temp, marker="o", ms=3)
ax.set_ylabel("Temperature (deg C)")
ax.set_ylim(22, 34)
ax.yaxis.set_major_locator(mticker.MultipleLocator(2))
ax.yaxis.set_minor_locator(mticker.MultipleLocator(1))
ax.xaxis.set_major_locator(mdates.DayLocator(interval=5))
ax.xaxis.set_major_formatter(mdates.DateFormatter("%m-%d"))
ax.tick_params(which="both", direction="in", top=True, right=True)
ax.grid(which="major", ls="--", alpha=0.35)
fig.autofmt_xdate()
fig.tight_layout()
plt.show()

常见错误与修正

日期轴太拥挤

每天都显示标签会重叠。修正：使用 DayLocator(interval=5)。

缺少单位

只写 Temperature 不够。修正：写成 Temperature (deg C)。

网格压过主体

网格太黑会抢注意力。修正：设置 alpha 和虚线。

课堂练习

把 y 轴主刻度改为 5 度、副刻度改为 1 度，并比较读图效果。

小结

坐标轴决定读者能不能准确读图，先调范围和单位，再考虑颜色和线型。
