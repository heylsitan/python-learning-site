核心概念

综合练习考查完整绘图流程：先确认数据字段，再选择图形类型，最后补齐坐标轴、图例、色标、说明文字和导出格式。若课堂提供 Weather.csv，字段建议包含 date、city、temp_max、temp_min、precipitation。

可替代 Weather.csv 的教学数据
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
date = pd.date_range("2015-07-01", periods=31)
weather = pd.DataFrame({
    "date": date,
    "city": "New York",
    "temp_max": 30 + 4 * np.sin(np.linspace(0, 2 * np.pi, 31)) + rng.normal(0, 0.6, 31),
    "temp_min": 21 + 3 * np.sin(np.linspace(0, 2 * np.pi, 31)) + rng.normal(0, 0.5, 31),
    "precipitation": rng.gamma(1.5, 2.0, 31)
})

时间序列图
import matplotlib.pyplot as plt
import matplotlib.dates as mdates

ny = weather[weather["city"] == "New York"]
fig, ax1 = plt.subplots(figsize=(10, 4), dpi=150)
ax1.plot(ny["date"], ny["temp_max"], color="tab:red", label="Tmax")
ax1.plot(ny["date"], ny["temp_min"], color="tab:blue", label="Tmin")
ax1.fill_between(ny["date"], ny["temp_min"], ny["temp_max"],
                 color="tab:orange", alpha=0.18, label="Daily range")
ax1.set_ylabel("Temperature (deg C)")
ax1.grid(ls="--", alpha=0.35)
ax1.legend(loc="upper left", frameon=False)
ax2 = ax1.twinx()
ax2.bar(ny["date"], ny["precipitation"], color="tab:blue", alpha=0.25)
ax2.set_ylabel("Precipitation (mm)")
ax1.xaxis.set_major_locator(mdates.DayLocator(interval=5))
ax1.xaxis.set_major_formatter(mdates.DateFormatter("%m-%d"))
fig.autofmt_xdate()
fig.savefig("newyork_201507_weather.png", dpi=300, bbox_inches="tight")

评分标准

项目比例要求
图形完成度40%图形类型正确，代码能运行，主体变量完整。
科学表达30%单位、图例、色标、刻度和标题能支撑结论。
规范输出20%文件名清晰，分辨率或格式选择合理。
解释说明10%能说明图形选择、色标范围或抽稀步长。

常见错误与修正

只提交图片不提交代码

无法复现。修正：同时提交脚本或 notebook。

没有说明色标范围

对比图不可解释。修正：在文字说明中写明 levels。

双坐标轴颜色不对应

读者分不清左右轴。修正：轴标签颜色与图层颜色一致。

小结

综合练习评价的是完整绘图流程：数据、图形、修饰、解释和保存，而不是只看图片是否好看。
