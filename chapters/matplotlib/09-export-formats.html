Matplotlib 09

图片保存与格式

理解 dpi、位图和矢量图格式，才能稳定输出论文级图片。

进阶选学建议 30 分钟

学习目标

  1. 能用 savefig 保存 PNG 和 PDF。
  2. 能解释 dpi 对位图输出的影响。
  3. 能区分位图和矢量图格式的适用场景。

核心概念

PNG/JPG/TIF 是位图格式，用像素保存图像；PDF/SVG/EPS 是常见矢量图格式，用路径、线条和文字保存图形。线图优先矢量图格式，复杂填色场可用高分辨率 PNG。

  • dpi 主要影响位图。
  • bbox_inches="tight" 可减少空白边。
  • 混合复杂图层时建议同时导出 PNG 和 PDF 检查。
最小可运行代码
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 10, 100)
y = np.sin(x)

fig, ax = plt.subplots(figsize=(5, 3), dpi=120)
ax.plot(x, y, lw=2)
ax.set_xlabel("x")
ax.set_ylabel("sin(x)")
fig.tight_layout()

fig.savefig("line_figure.png", dpi=300, bbox_inches="tight")
fig.savefig("line_figure.pdf", bbox_inches="tight")
plt.close(fig)

常见错误与修正

保存图模糊

低分辨率 PNG 被放大。修正：提高 dpi 或导出 PDF/SVG。

图边空白太大

默认边距保留太多。修正：使用 bbox_inches="tight"。

矢量图格式文件过大

大量栅格填色对象被写入 PDF。修正：复杂填色场改用高分辨率 PNG。

课堂练习

保存同一张线图为 PNG 和 PDF，放大到 300% 比较文字和线条边缘。

小结

线图和文字多的图优先矢量图格式；像素场、影像图和复杂填色图优先高分辨率位图。
