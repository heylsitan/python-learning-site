学习目标

  1. 能在 JupyterLab 或 Python 脚本中运行第一段程序。
  2. 理解 print() 的基本作用和参数写法。
  3. 知道 input() 默认返回字符串，并能进行简单类型转换。

第一个程序

Miniconda 或课程环境准备好后，可以先在 JupyterLab 中运行最小程序。

Hello World
print("Hello World!")

程序简析

  • print() 是 Python 内置函数，用来输出括号中的内容。
  • "Hello World!" 是字符串，作为参数传给 print()。
  • 函数执行后默认换行。

第一段程序的意义不是内容复杂，而是确认“环境、入口、解释器”三件事已经连通。

print 的基本用法

输出多个参数
country = "China"
year = 2026

print("Country:", country)
print("Year:", year)
print("China", country, year)
print("不换行输出", end="")
概念提醒

引号内的内容是字符串常量，会照原样输出；没有引号的名字通常是变量，会输出变量当前保存的内容。

input 函数

input() 是 Python 中最基本的输入方法。括号里的提示信息会显示在屏幕上，用于提示用户输入。

读取输入
name = input("请输入姓名：")
print("你好，", name)

默认类型

input() 接收到的数据默认是字符串。如果要作为数字计算，需要用类型转换函数。

转换为整数
age = input("请输入年龄：")
print(type(age))

age = int(input("请输入年龄："))
print(type(age))
