AI Agent 编程初体验

AI 改变编程方式，但不替代科学问题判断。

课后实践建议 30 分钟

学习目标

  1. 理解 AI Agent 编程与传统手写代码的差异。
  2. 能把一个绘图任务描述给 Agent，并通过反馈迭代结果。
  3. 知道人类在 AI 编程时代仍需负责需求拆解、结果验证和错误判断。

编程场景的变化

传统编程模式

  • 手动编写每一行代码。
  • 人工查阅文档并调试错误。
  • 以语法实现为核心能力。
  • 复杂任务往往需要数天开发。

AI Agent 编程模式

  • 从代码补全发展到任务代理。
  • AI 可读取项目、修改代码并参与调试。
  • 开发者更关注任务拆解与结果验证。
  • 部分任务可从数天缩短到数分钟。
关键判断

AI 改变的是编程方式，不是科学思维的重要性。程序员逐渐从代码直接生产者转向 AI 的指挥者与审核者。

工具准备

课件以 Trae 和 DeepSeek API 为例，核心流程是安装编辑器、添加模型、配置 API key，再让 Agent 读取需求并生成代码。

API key 属于个人敏感信息。课堂展示时不要公开投屏完整 key，也不要把 key 写进代码仓库。

建议先做什么

先完成普通 Python 环境和 Hello World，再尝试 AI Agent。否则无法判断 Agent 报错到底来自需求、代码还是环境。

课后实践任务

利用 AI Agent 自动生成代码，绘制中国各省地图，并使用不同颜色进行填充。

  1. 只能向 AI Agent 描述需求。
  2. 不断补充修改意见。
  3. 让 Agent 自动完成代码生成与调试。
  4. 最后由你检查图件是否正确、清晰、可解释。

提示词起点

可复制的任务描述
请用 Python 绘制中国各省级行政区地图。
要求：
1. 每个省使用不同颜色填充；
2. 图中显示省界；
3. 输出一张 PNG 图片；
4. 代码需要包含数据来源说明；
5. 如果缺少依赖，请自动给出安装命令并解释用途。

思考问题

AI 是否真的理解了你的需求？

看它是否画出了省级行政区，而不是只画国界或示意图。

你在哪些地方修正了提示词？

记录关于数据源、投影、颜色、边界、标签和输出格式的修改。

结果是否存在错误或不合理？

检查地图范围、边界缺失、颜色含义、依赖安装和文件路径。

小结

AI Agent 能加速从需求到代码的过程，但课程仍要求学生能运行、解释、检查和修正结果。
