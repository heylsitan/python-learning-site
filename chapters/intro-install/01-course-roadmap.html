Intro 01

学情调查与课程安排

先确认学生从哪里来，再决定课堂推进节奏。

首页本章首页下一节
课程导入建议 20 分钟

学习目标

  1. 明确本课程面对编程零基础学生，但不降低大学课程的系统性要求。
  2. 理解课程的三个目标：夯实基础能力、培养自主学习能力、提升核心竞争力。
  3. 知道后续 11 讲的主线安排。

学情调查的三个问题

在此之前，你写过代码吗？你学 Python 最想用来干什么？你觉得这学期自己能学会 Python 吗？你希望课堂多讲原理还是多做练习？

调查不是为了分层贴标签，而是帮助教师判断哪些概念要放慢、哪些任务可以提前给挑战题。

课堂判断

零基础同学最需要的是“可以复制、可以验证、可以排错”的路径；有基础同学则需要项目型挑战，避免只重复语法。

后续使用

将学生目标分为基础语法、数据处理、绘图、科研自动化和 AI 辅助编程几类。

课程定位

这是一门面向编程零基础、但体现大学水平的 Python 语言入门课程。零基础意味着从环境和第一行代码开始，大学水平意味着围绕 Python 基础语法形成体系化理解，并逐步过渡到科学计算和气象数据处理。

一句话目标

让所有同学能独立运行、阅读、修改基础 Python 程序，并为后续 NumPy、Pandas、Xarray、Matplotlib 和 Cartopy 做准备。

课程大纲

序号主题核心任务
01Python 简介及环境安装完成环境搭建并运行第一段程序。
02基本数据类型、变量和运算符掌握数据和表达式的基础。
03分支、循环与条件让程序能按条件和重复规则执行。
04包、模块、函数与变量作用域把脚本组织成可复用结构。
05面向对象、函数式编程理解更高级的代码组织方式。
06-08NumPy、Pandas、Xarray进入科学计算、表格数据和多维气象数据。
09-10Matplotlib、Cartopy完成时间序列图、二维场和地图绘制。
11综合练习把数据读取、计算、绘图整合成完整任务。

课堂练习

请写下你最希望用 Python 解决的一个学习或科研问题，并标记它更接近“自动化、数据处理、绘图、AI 辅助、其他”中的哪一类。

小结

第一讲的目标不是马上掌握很多语法，而是建立学习路线、运行环境和自我排错意识。
