学习目标

  1. 区分源代码和目标代码。
  2. 能用自己的话解释编译和解释两种执行方式。
  3. 知道 Python 的诞生、特点和主要应用领域。

程序设计语言是什么

源代码是人类可读的程序文本，例如 result = 2 + 3。目标代码是计算机可以直接执行的形式，普通学习者通常不直接阅读。

1写源代码
2交给工具翻译
3执行程序
4输入数据
5得到结果
一行源代码
result = 2 + 3
print(result)

编译与解释

编译

将源代码一次性转换成目标代码，之后执行目标代码。可以类比成提前完成整篇翻译。

解释

程序运行时由解释器逐条翻译并逐条执行。可以类比成实时同声传译。

Python 通常被归入解释型语言，所以同学们安装的 Python 解释器就是后续运行代码的关键工具。

Python 的发展与气质

Python 由 Guido van Rossum 创建，1989 年开始设计，1991 年发布第一个公开版本。Python 2.x 于 2002 年后广泛使用，Python 3.x 于 2008 年发布并成为现代课程的默认选择。

Python 之禅的课堂理解

简洁、明了、可读性高。对初学者来说，可读性意味着能看懂自己的代码；对科研代码来说，可读性意味着别人能复现实验。

应用领域

人工智能

机器学习、神经网络、深度学习。

科学计算

NumPy、SciPy、Matplotlib。

数据分析

数据清洗、可视化和统计处理。

网络爬虫

网页数据获取和批量处理。

云计算

OpenStack 等开源生态。

自动化运维

脚本、批处理和测试自动化。

Web 开发

Django、Flask 等框架。

常规软件开发

工具脚本、网络编程和桌面辅助。

常见误区

Python 简单等于不用认真学

语法入门容易，但数据结构、模块组织和科研复现仍然需要训练。

解释型语言等于运行一定慢

科学计算中大量底层计算由优化库完成，关键是写出合适的数据处理流程。

只记语言排名

排名不是学习目标，能解决具体数据和绘图任务才是目标。
