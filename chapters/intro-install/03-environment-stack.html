学习目标

  1. 说清操作系统、Python 解释器、conda 环境、编辑器和 Notebook 的分工。
  2. 能用命令检查 conda 是否安装成功。
  3. 理解为什么每个项目最好有独立环境。

先把几个词分清

操作系统

Windows、macOS、Linux，提供终端和文件系统。

Python 解释器

真正执行 .py 代码的程序，命令通常是 python 或 python3。

包与环境

conda 管理包；每个项目最好有独立环境。

编辑器 / Notebook

VS Code 适合写脚本，JupyterLab 适合边算边看。

关键原则：不要把系统自带 Python、课程环境、编辑器混成一件事。

安装后先验证

在 Anaconda Prompt、终端或系统 shell 中运行：

检查 conda
conda --version
conda info
conda env list

看到什么算成功

  • 能显示 conda 版本号。
  • env list 中至少有 base 环境。
  • 没有出现 not recognized、command not found 等错误。

如果命令找不到，先确认是否打开了正确终端，再检查安装路径和环境变量。

课程常用命令

环境与包管理
conda create -n pycourse python=3.11
conda activate pycourse
conda install numpy pandas xarray matplotlib jupyterlab
conda list
conda deactivate
课堂标准

本课程以 conda 环境为标准路径。学生不需要管理员权限，也不需要改动系统 Python。

国内镜像与缓存

如果下载包很慢，可以使用课程推荐的镜像配置。配置后建议运行 conda clean -i 清除索引缓存，确保使用新的索引。

检查配置
conda config --show channels
conda clean -i
